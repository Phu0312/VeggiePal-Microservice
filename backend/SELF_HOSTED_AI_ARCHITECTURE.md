# Self-hosted AI architecture

Chat, meal planning, recommendations and text moderation use `LocalAiClient` directly. It sends OpenAI-compatible `/v1/chat/completions` requests to one local llama.cpp server running Qwen2.5-1.5B-Instruct. There is no remote inference provider or provider selection setting. The Docker AI service reaches `http://llama:8080/v1` on the private Compose network; a host process can use `http://127.0.0.1:8088/v1` through `AI_LOCAL_BASE_URL`.

Chat preserves quota reservation, conversation history (bounded to `MAX_TOTAL_HISTORY_CHARS = 3200` and `maxInputCharacters = 4000` to protect the 2,048-token context window) and persistence, and applies a context-aware post-generation safety layer (`enforceVeganAndSafetyBoundaries`) that sanitizes unnegated animal-product leaks while preserving educational explanations and enforcing Vitamin B12, diabetes, acute symptom, and portion-uncertainty disclaimers. Meal planning filters recipes and allergens in Java, compacts prompt candidates to 20 balanced recipes (`compactPromptCandidates`), asks Qwen for a single-line compact JSON schedule (`maxTokens=550`), validates the selected IDs, optimizes serving multipliers within `[0.75, 1.50]`, and derives nutrition values from recipe-service data. Its deterministic planner recovers from invalid generated output; an unavailable local inference server returns HTTP 503. Recommendations rank up to 24 safe candidates (`MAX_PROMPT_CANDIDATES = 24`, `maxTokens=500`) fetched from blog-service and recipe-service, filter recipe candidates against the user's allergens with the meal planner's validator, discard IDs absent from those candidates, and provide a deterministic Vietnamese explanation (`ensureMeaningfulReason`) from verified candidate metadata whenever the model returns a blank `reason`. A failed allergy lookup returns a controlled downstream error. Blog recommendations contain published content rather than structured ingredient data, so ingredient-level allergy screening applies to recipe candidates only. Moderation wraps untrusted user text inside `<untrusted_content>...</untrusted_content>` with `<` and `>` escaped (`maxTokens=220`), asks Qwen to generate `reason` and `categories` before `decision` (chain-of-thought ordering), and applies a deterministic calibration pipeline (`calibrateModeration`) that blocks severe violations and prompt-injection attempts, routes ambiguous health claims and community disputes to `REVIEW_REQUIRED`, and prevents false rejections of benign vegan cooking and food-safety posts; inference failure queues `REVIEW_REQUIRED` (`ai_fallback`) for an administrator. The moderation endpoint receives text only, including for VIDEO content; Qwen does not inspect frames or pixels.

The model is Qwen2.5-1.5B-Instruct, quantized as GGUF Q4_K_M. The [official GGUF repository](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF) lists the 1.12 GB file and Apache 2.0 license. Four-bit quantization reduces weight memory relative to the FP16 file (3.56 GB). llama.cpp reads this GGUF directly and offloads all 29 transformer tensors (`LLAMA_GPU_LAYERS=99`) onto the NVIDIA Quadro T2000 (consuming `1,095 MiB / 4,096 MiB` VRAM and `1,651–1,743 MiB` container RAM at `--ctx-size 2048 --parallel 1 --batch-size 256`). ONNX conversion adds a second model format and runtime without a benefit for this shared generative path; a future dedicated classifier could use ONNX separately. The [llama.cpp server guide](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md) documents `/health`, `/v1/chat/completions`, context, batch, parallel and GPU-layer options. The [Docker guide](https://github.com/ggml-org/llama.cpp/blob/master/docs/docker.md) documents the CUDA server image.

Current limitations: a 1.5B text model can still misclassify nuanced Vietnamese content that falls outside calibrated patterns; confidence returned by the model is an uncalibrated score. Moderation sends uncertain or failed classifications to manual review. Single-slot execution (`--parallel 1`) serializes concurrent requests in FIFO order to protect the 4 GB VRAM budget.
